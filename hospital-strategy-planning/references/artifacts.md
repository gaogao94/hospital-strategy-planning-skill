# 产物模板（artifacts）

规则：
- 只在对应步骤落盘，**不要一次把全部模板倒给用户**。
- 更新用「追加/替换该节」，不要每步重写整份文件。
- 缺数据写 `【待补】`，并在文件末尾的【待补】清单登记：`项 | 找谁补 | 期限`。
- 每个数字标来源：`（用户）`、`（稿）`、`（公开）`；交卷时列「未核来源」清单。
- 模板里的「例：…」「__」「……」是给 Agent 看的示例；**落盘时必须换成真实内容，交付物不留占位符**。
- 落盘后只回一句：`已落盘：规划底稿.md §2`。
- 没有文件工具时：先把文件写一次；失败才降级为折叠块 + 对话内底稿摘要，并每轮末尾报 `当前步｜已过闸门｜待补数`。

## 工作目录约定

```
规划底稿.md      # 主底稿，按 §1–§11 逐节长出来；可随时停、随时续
战略一张图.md    # 第 6 步的落盘，五层 + 不做什么 + 三句话测试
汇报稿.md        # 第 8–11 步：四段提纲、答辩三问、一页纸、通用叙事三句
体检报告.md      # 模式 B 的落盘，11 行体检表
STATE.md         # 模式/当前步/未过关/关键待补，方便换会话续跑
```

## 第 8 步 `汇报稿.md` 四段提纲

```markdown
# 战略汇报（v__）

## 一、我们面对什么问题（≤1/4 篇幅）
## 二、做了什么取舍（≤1/4）
## 三、结果怎么样（≥1 个真实数字，含基线对比）
## 四、哪里没做到，学到了什么（具体一件事 + 学到什么，不许写「基本达成/略有不足」）

篇幅自查：第三+第四段 ≥ 一半（字数：三 ＿＿ 字 / 四 ＿＿ 字 / 全文 ＿＿ 字）。
```

## 第 9 步 答辩三问

```markdown
## 答辩准备（20 分钟讲述 + 10 到 15 分钟答辩）
汇报人：书记 / 院长 / 分管领导：____
1. 你们放弃了什么？

```

## 模式 B：体检表（审稿用，落盘 `体检报告.md`）

规则：先通读全文；每行判决 ✅/⚠️/❌ 配**稿中原句 ≤30 字 + 位置**（如「§2 第 3 段」），不许用「……」占位。**11 行表作为产物块贴出（≤15 行）并落盘 `体检报告.md`**，贴完只报最疼 3 条。

```markdown
| # | 检查项 | 判决 | 依据（稿中原句 + 位置） |
|---|---|---|---|
| 01 | 市场与竞争分析 → 定位 → 取舍 | ❌ | 「我院区位优势明显」§1 第 1 段，无对手、无外转数据 |
| 02 | 挑战是否带数字、到科室病种 | ⚠️ | 「人才梯队有待加强」§3 第 2 段 |
| 03 | 选题遮住院名能否认出 | ❌ | 「推动高质量发展」§1 标题 |
| 04 | 指标-举措-结果是否对得上 | ❌ | 指标一套、举措一套、结果一套，无对照 |
| 05 | 删掉工具还剩什么业务目标 | ⚠️ | 全文以 BSC、SWOT、PEST 起章节 |
| 06 | 五层一张图 + 资源绩效配称 | ❌ | 无预算、无绩效挂钩 |
| 07 | 四维结果对照表 | ⚠️ | 只有业务量，无基线、无健康结果 |
| 08 | 四段汇报、三四段占一半 | ❌ | 全文「怎么做」，结果一段带过 |
| 09 | 资深汇报人 + 答辩机制 | ⚠️ | 未写汇报人与答辩时间 |
| 10 | 一页纸 + 结论句标题 | ❌ | 68 页，标题为名词短语 |
| 11 | 通用叙事映射 | — | 未规划（可不做） |
```
体检后：只报**最疼的 3 条**（每条一句依据 + 一句改法），然后问一句：先改哪条？
